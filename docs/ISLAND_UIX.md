# 新しい画面（方向 C「管制卓」）：見た目と手触りの土台

My Crypto Successor の UI・部品・動きを作り直すための決まりと部品（段 UIX1a）。基本のサイクル・ゲームの数字・セーブは変えない。
触って決めた見本は `public/uixlab/c/`（手触りラボ C。書き換えない）。本体へは「作り直す」のではなく「移す」：色・形・動きの長さは見本の値をそのまま使う。
音は別の文書（音の土台の段）にまとめる。

## 1. 主題と、決めの 3 手

ドット絵の町と地続きの「機械の卓」。UI は町と同じ画素の升目に乗り、スイッチ・ランプ・計器・紙テープ・貼り札でできている。

1. **遷移＝網目の幕**：押した場所から画素の升目が順に埋まり、暗転の中央に行き先の札が出て、同じ順で晴れる。
2. **承認＝レバーを引き下ろす**：目盛りごとに「カチ」、下まで行くと「ガチャン」で光・揺れ・火花・振動。続いてランプが順に点き、「承認済」が点く。押すだけでも落ちる。
3. **数字＝桁が回る**：資金・売上・個数は機械のカウンター。下の桁が 9→0 に回るあいだだけ、上の桁が一緒に回る。

## 2. 切り替え（大事）

本体の画面は 45 ほどある。全部が移り終わるまで、ふだんの見た目は今のまま保つ。

- 新しい見た目は、`<html>` に class **`is-uxc`** が付いているときだけ。**既定は切**で、切のときは今の画面と 1 画素も変わらない。
- 入れ方：設定の「新しい画面（試作）」、または URL の `?uix=1`（入）・`?uix=0`（切）。URL で指定したら端末に覚える（`localStorage` の `isl.uxc`。セーブとは別で、セーブの版は上げない）。
- `src/island/uix/flag.ts`：`uxOn()`・`setUx(on)`・`initUx()`。起動のいちばん早い所（`src/island/main.ts`）で決める。class を付け外しするたびに、`window` に `CustomEvent('uxc:change', { detail: { on } })` を出す（音の側は、この class と event だけを見る）。
- **切のときは、新しい分を読まない**：値・部品の CSS・書体・上掛けの canvas は `src/island/uix/boot.ts` にまとめ、入のときだけ動的に読む（`import('./uix/boot')`）。切のときに読むのは、切り替えの `flag.ts`・差し込み口の `hooks.ts`・音の口の `sound.ts` の小さな 3 つだけ。
- 新しい CSS のセレクタは、すべて `html.is-uxc` の内側に書く（`tests/island-uix1a.test.ts` が確かめる）。新しい class の接頭辞は `ux-`。
- 入のとき、まだ移していない画面が粗く見えるのはかまわない。ただし、操作できなくなる・進めなくなることは無いようにする。

## 3. 値（`src/island/uix/tokens.css`）

名前は `--ux-*`。見本の `css/base.css` の値そのまま。

| 種類 | 変数 | 中身 |
|---|---|---|
| 機械の胴 | `--ux-k0`〜`--ux-k5` | 暗い順。`k0 #0b0d17`（縁・影）・`k1`（中の面）・`k2`（板）・`k3`（キーの面）・`k4`（縁の光）・`k5 #97a1cf`（弱い字） |
| 貼り札・紙 | `--ux-paper`・`paper2`・`paper3`・`--ux-ink` | 読ませる面は紙（`#f4ecd4`）に墨（`#1a1c2e`） |
| ランプ | `--ux-amber`（主）・`--ux-good`・`--ux-bad`・`--ux-cyan`・`--ux-white` | それぞれ `-hi`・`-lo`（縁の光と影） |
| 升目 | `--ux-u: 2px` | 寸法・余白・縁はすべて 2px の倍数。角は丸めない |
| 切り欠き | `--ux-notch`・`--ux-notch4` | 階段の角（2px・4px）。`clip-path` に使う |
| 網目 | `--ux-dz50`・`dz25`・`dz50w`・`dz25w` | 暗くするのは網目と暗い色で。ぼかし・全面の合成は使わない |
| 字の段 | `--ux-t1`（16px）・`t15`・`t2`・`t3` | 日本語は 16px が最小。16px の整数倍を基本にする |
| 数字の段 | `--ux-n15`・`n2`・`n3`・`n4` | 数字の書体の画素が整数倍になる大きさ |
| 動き | `--ux-d-press 60ms`・`d-switch 90ms`・`d-toast 160ms`・`d-out 180ms`・`d-dim 200ms`・`d-in 260ms`・`d-page 520ms`・`d-big 1800ms` と `--ux-e-*` | イーズは `steps()`（カクカクと「機械が切り替える」動き）。押す 60〜90ms・出入り 180〜260ms・めくり 500〜700ms・大きな演出 1.5〜3s |
| 重なり | `--ux-z-sheet 45`・`z-fx 55`・`z-wipe 60`・`z-toast 70`・`z-cut 75`・`z-crt 90` | body の直下に置く層の順 |

- 色の組は 2 つ：ふつうと、色覚に配慮（`is-cvd`：良い＝青・急ぎ＝橙）。意味は色だけで伝えない（形と言葉を添える）。
- 文字の大きさは `<html>` の `font-size`（100%＝16px・115%・130%）。新しい部品は `rem` で書く。
- いまの色の変数（`--isl-*` の 10 個）は、入のとき管制卓の色へ寄せてある（`base.css`）。まだ移していない画面も、同じ色の組で出る。

### 書体
- 日本語は **DotGothic16**、数字と英字は **Jersey 10**（どちらも SIL Open Font License 1.1。文は `public/fonts/OFL-DotGothic16.txt`・`OFL-Jersey10.txt`）。
- npm の `@fontsource/dotgothic16`・`@fontsource/jersey-10` から取り、unicode-range で分かれた woff2 を自前で配る（外部の CDN からは読まない）。ブラウザは、画面に出た字を含むファイルだけを取りに行く。
- 入のときだけ読む。読めるまでは今の書体で出る（`font-display: swap`）。
- サービスワーカーは、分かれた書体のファイルを事前には保存しない（使ったときに覚える。`vite.config.ts`）。
- DotGothic16 に無い字（絵文字・一部の記号・ごく一部の漢字）は、今の書体で出る。
- 太字は合成させない（`font-synthesis: none`）。強調は 1px の影で太らせる（`b`・見出し）。

## 4. 部品（`src/island/uix/parts.ts`・`parts.css`）

画面は、この部品だけで組む。見本帳（`?uix=kit`）に全部並んでいる。

| 部品 | 使い方 | 決まり |
|---|---|---|
| キー（ボタン） | `uxKey(label, fn, { kind, big, ico, disabled })` | 種類は 4 つまで：`main`（琥珀。1 画面に 1 つ）・ふつう・`weak`・`danger`。押すと 60ms で 4px 沈む。押せないものは平ら。44px 以上 |
| 板 | `uxPlate(cls, ...kids)` | 機械の胴の板・四隅のねじ。浮いている板は `ux-float` の箱で包む（固い影） |
| 貼り札 | `uxTape(label, kind)` | 見出し・ラベル。紙テープの見出しは `ux-rl-k` |
| ランプ | `uxLamp(kind, on, blink)` | 点く・またたく（0.9 秒） |
| 計器 | `uxMeter(v, kind)` → `set(v)`・`flash()` | 進みのバーはこの 1 つにまとめる。20 段の目盛り |
| カウンター | `new Odo({ digits, size })`・`set(v, { dur })` | 桁が回る |
| 作り直しをまたぐ数字 | `rollNumber(key, value, { plus })` | 同じ鍵で前に出した値を覚えていて、画面を丸ごと作り直しても、前の値から新しい値へ回る |
| 「+N」 | `uxPlus(el, n)` | 増えた・減ったぶんが数字の上に飛び出して消える（900ms）。上掛けの層に出す |
| レバー | `uxLever({ onDone, can })` → `el`・`lamps`・`done` | 引く・押すのどちらでも落ちる。落ちたら 1 回だけ呼ぶ |
| スイッチ・つまみ | `uxToggle()`・`uxFader()` | つまみは 2px の格子に乗る |
| 吹き出し | `uxBubble({ face, name, lines })` → `start()`・`pointAt(x)` | 中身の長さで枠が伸び縮みする。尻尾は話す人か建物を指す。1 字ずつ出す（押すと最後まで） |
| 枠破り | `uxStand(sprite, 2)` | ヒーローがパネルの縁からはみ出して手前に立つ。息をする。ドット絵は整数倍 |
| お知らせ | `uxToast(msg)` | 上の帯のすぐ下の短い紙。160ms で出入り |
| アイコン | `uxIcon(name)` | 12×12 のドット絵。絵文字は使わない |

- 押す手応えは `press(el, fn)`。押した瞬間に沈み、すばやく叩いても沈んだ形が見える（70ms）。
- 上掛けの canvas は 1 枚（`fx.ts`）：金貨・火花・紙ふぶき・押した印・網目の幕。動かすものが無いあいだは描かない。粒は 260 個まで。
- 網目の幕は `wipe(origin, mid, { label, reverse })`：閉じる 230ms・止まる 50ms・晴れる 250ms。`mid` で裏の画面を入れ替える。

### 音の口
`src/island/uix/sound.ts` の `uxSfx(name, { pitch, voice, step })`。部品はこれを呼ぶだけ。名前は `press`・`release`・`open`・`close`・`page`・`tab`・`lever`・`clunk`・`lamp`・`coin`・`cash`・`deny`・`confirm`・`rankup`・`conquest`・`build`・`done`・`tick`・`blip`・`toggle`・`slide`・`error`。

## 5. いまの入口への差し込み（`hooks.ts`・`legacy.ts`・`legacy.css`）

入のとき、いまの入口がそのまま新しい器と手応えになる。画面ごとの作り込みは、このあとの段。

| 入口 | 入のとき |
|---|---|
| `btn()`（`.isl-btn`） | 見本のキーの形（胴・縁の光・切り欠き）。`is-on`＝主・`is-danger`＝危ない・`disabled`＝平ら。字は 16px（今は無効な `font` の短縮形で 13.33px・細字になっている。切のときはそのまま） |
| すべてのボタン | 押した瞬間に沈む。押した印（枠が外へひろがる）は上掛けの層に出すので、押したボタンが作り直されても残る |
| `sheet()` | 機械の板・ねじ・✕ のキー。地図から開く・地図へ閉じるのは網目の幕。**✕ や外側で閉じるときは、幕が閉じきるのを待ってから消す**。札から札へは短い出入り（220ms）。開いているあいだ、地図は暗い網目で落とす |
| `modal()` と、直接作っている 10 か所 | 共通の口 `ux.modal(m, kind)` を通す：暗い網目の幕・入る動き。`modal()` の箱は機械の板 |
| お知らせ（`toast`） | 短い紙。札・窓を開いているあいだは、中身に重ならない上の帯の上に置く |
| 承認のボタン | `ux.lever(b)` でレバーに替える（輸入の受け箱・予算の承認待ち・部長との会話の 3 か所で試している）。落ちたら、もとのボタンを 1 回押す |

- 呼ぶ側は `ux.x?.()` と書く。切のときは口が空なので、何も起きない。

## 6. 止まらない画面・動きを減らす

- 止まらない動き：主のキーに光の帯が走る（5.2 秒に 1 回）・ランプのまたたき・計器の進み・立ち絵が息をする。動かすのは transform と opacity。
- **動きを減らす**は 1 つの class `is-calm`：設定の「動きを減らす」（自動／入／切）と、端末の設定（`prefers-reduced-motion`）で付く。
  - CSS の動きはすべて止まる（いまの画面の動きも）。幕は淡い切り替えだけになり、粒・揺れ・振動は出さない。カウンターとレバーはすぐ結果になる。
  - いまの「演出：ふつう／控えめ／なし」（ドットの効果の強さ）はそのまま残す。入で `is-calm` のあいだは、設定によらずドットの効果を出さない。
- 走査線（`is-crt`）は設定で入り切りできる。重いときは自動で切る。

## 7. 設定（入のときに出る欄）

文字の大きさ（100・115・130%）・動きを減らす（自動／入／切）・色覚に配慮・吹き出しの速さ（ゆっくり・ふつう・はやい・すぐ）・走査線。端末に覚える（`isl.uxc.prefs`）。

## 8. 性能

- 上掛けの canvas と部品の動きは、動かすものがあるあいだだけ rAF を回す（地図の描画ループには触らない）。
- 90 コマの平均が 22ms を 2 回続けて超えたら、効果を 1 段落とす（粒の数 1 → 0.7 → 0.45・流れる帯を止める）。いちばん下の段では走査線も切る。

## 画面：上と下の帯

段 UIX2m。見本は `public/uixlab/c/js/hud.js`・`css/scenes.css`（上の帯・テロップ・下の帯）。コードは `src/island/uix/screens/`：入口 `mapui.ts`（入のときだけ `p1/main.ts` が動的に読む）・`hud.ts`・`dock.ts`・`hud.css`・足したアイコン `micons.ts`・口 `mhooks.ts`（`uxm`。切のときは空）。class の接頭辞は `uxm-`。

**作り方（大事）**：今の要素は消さない。押す先・出す隠す・チュートリアルの目印は、今の描き直し（`renderHud`・`renderFoot`・`renderMissions`）が決めたまま使う。
- 新しい画面の束は、本体のコード（`p1/`）を import しない（型だけ）。要る関数（日付・売上・課題の札 ほか）は `p1/main.ts` が `host.api` で渡し、担当の顔・名前・ひと言は今の吹き出しの要素から読む。入のときだけ読む束が、本体の束（切のときに読む束）の分かれ方を変えないようにするため（本番のビルドで、本体の CSS と JS の束は main と同じ分かれ方のまま）。
- 数字の札（`.isl-stat`）は、新しい計器の下に**透明のまま重ねる**（押す先・読み上げ・ブランド力の光の場所に使う）。新しい見た目は `aria-hidden`。
- 速さのボタン・タブ（`.isl-tab`）・ミッション・拡大縮小・地図の印は、**今の要素を着せ替える**（中身をキーの箱に入れ、絵文字をドットの絵に替える）。`is-guide`・`is-lock`・`is-on`・`has-dot`・`has-num` はそのまま効く。

## 画面：建物の吹き出し

段 UIX2m。見本は `public/uixlab/c/js/pop.js`・`world.js`（カメラの寄り）。コードは `src/island/uix/screens/pop.ts`・`pop.css`。吹き出しの器・枠の伸び縮み・1 字ずつ喋る・枠破りは土台の `uxBubble`。

## 前の層（主役のボタンには、走査線を乗せない。`src/island/uix/front.ts`）

走査線は、画面全体のいちばん上にかぶせた 1 枚（`.ux-crt > .ux-crt-lines`）なので、その下の字にはどれも同じ線が乗る。演出としてはよいが、押して動かすボタンの字まで読みにくくなる。そこで、**画面ごとの主役のボタンだけは、その 1 枚に同じ形の窓を開けて、線の乗らない、はっきりした見た目にする。** 背景と、読むだけの字には今の演出が残るので、「読むだけの字」と「押して動かす主役」が、線のある・なしで見分けられる。

- **前の層に出るもの**（`FRONT_SEL`）
  - 主のキー（`uxKey(..., { kind: 'main' })`。琥珀。1 画面に 1 つが基本）
  - 承認のレバー（`.ux-lever`）
  - 下の帯の主（経営企画：`.isl-tab.is-center`）
  - まだ移していない窓の「推奨」の選択肢（`.isl-cardm-btn.is-rec`）
  - 画面が名指しした物（class `ux-front`。例：建物の吹き出しの主役のキー＝並びの先頭の琥珀のキー）
- **これから移す画面での使い方**：その画面の主役は、主のキーで作る（それだけで前の層に出る）。今の要素を着せ替えるだけの所は、主役の 1 つに class `ux-front` を付ける。**主役は 1 画面に 1 つ（多くて 2 つ）**。数を増やすと「どれが主役か」が消えるので、ふつうのキーは入れない（1 画面の上限は `FRONT_MAX`）。
- **作り**：毎コマ、前の層の要素の位置を読み、走査線の 1 枚の `clip-path`（外側の四角＋窓。`evenodd`）を作り直す。変わったときだけ書きこむ。
  - 形は、見えている分だけ（画面の外・はみ出しを切る箱の外は除く）。札の中を送って半分隠れたキーは、見えている分だけ窓が開く。
  - **隠れている物には開けない**：上・中・下の 3 点とも、その要素が手前にあるときだけ（`elementFromPoint`）。別の窓や札の下にあるキーに窓を開けると、手前の物の上に四角い「線の無い所」ができるため。形が変わらないあいだ、この確かめは `PROBE_EVERY` コマに 1 回。
  - 幕（網目の遷移）が出ているあいだは開けない。押せないキー（`disabled`）は出さない。
  - 走査線が切のとき（設定・重い端末で自動）は、何もしない。`clip-path: path()` が使えない環境でも何もしない（今までどおり全部に線が乗る）。
  - ゆっくり流れる明るい帯（`.ux-crt::after`）は、窓を開けずに全体へかけたまま（線ではないので、字は読みにくくならない）。
- **重さ**：止まっている画面では、1 コマの平均が 0.01ms 未満（位置を読むだけ。手元のヘッドレスでの計測で、実機では測っていない）。390・1280 で、吹き出しの立ち上がり・カメラの寄りのあいだも、窓はキーと同じコマで動く（ずれたコマ 0）。

## 画面の部品（`src/island/uix/sparts.ts`・`sparts.css`。class は `uxp-`）

段 UIX3a。土台の部品（キー・ランプ・計器・カウンター…）を組んだ、**画面を作るときの決まった形**。残りの画面は、これで組む（同じ役目の部品を、画面ごとに作らない）。見本帳（`?uix=kit` の「画面の部品」）に全部並んでいる。CSS は土台といっしょに読むので（`boot.ts`）、画面の側で読み込む必要は無い。本体（`p1/`）は読まない：ヒーロー・商品の絵は、呼ぶ側が要素で渡す（`D.heroIcon(id, 64)` など）。

| 部品 | 使い方 | 決まり |
|---|---|---|
| 見出しの貼り札（節） | `uxpHead(title, { kind, ico, note, right })` | 節のはじめに 1 つ。貼り札 ＋ 右へ伸びる点々の罫。右端に数の札・小さなキーを置ける |
| 行 | `uxpRow(name, value, { ico, note, tone })` | 名前 …… 値（点線でつなぐ）。添え書きは下の行。`tone`：`good`・`bad`・`amber`・`dim`（色だけに頼らず、符号・言葉を値に入れる） |
| 数字まじりの値 | `uxpNum('12.1万')` | 頭の数字は数字の書体、うしろの言葉（万・個・人）は日本語の書体 |
| 数字の札 | `uxpStat(label, value, { key, unit, digits, size, tone, plus })` → `set(v)` | 貼り札の名前 ＋ 桁の回るカウンター。`key` を渡すと、画面を作り直しても前の値から回る。並べるときは `div.uxp-stats` に入れる |
| タブ | `uxpTabs([{ key, label, ico, build, onShow, dot }], { initial, onChange, flow })` → `el`・`set(key)`・`dot(key, n)` | 520ms・8 段の横送り。開いているタブはランプが点いて沈む。`build` は、はじめて開くときに 1 回。`flow: true` は、中身の高さに合わせる（札の中を縦に送る画面）。既定は残りの高さいっぱいの窓 |
| 届いた印 | `uxpDot(n)` → `set(n)` | 赤いランプがまたたく。`0`＝ランプだけ・1 以上＝数つき・`null`＝出さない |
| 一覧のカード | `uxpCard({ pic, name, tags, desc, foot, right, badge, onTap, selected, off })` | 絵・名前・説明・右にキー（せまい画面では、キーは下の段）。`onTap` を渡すと、カード全体が押せる（選ぶ一覧）。並べるときは `div.uxp-list`（縦）・`div.uxp-grid`（列） |
| 選んだ形にする | `uxpSelect(card, on, feel)` | ランプ・琥珀の枠。`feel` で押し込まれた音と小さな動き |
| 「あと N G」の目盛り | `uxpGap(have, cost, { unit, hint })` → `set(have, cost)`・`nudge()`・`short` | 足りないときだけ出る。足りないまま押されたら `nudge()`（やわらかい音・目盛りが進む）。赤い × で終わらせない |
| 値段 | `uxpPrice(cost)` | 金貨の絵 ＋ 数字。0 なら「無料」 |
| 空のとき | `uxpEmpty(text, { ico, sub, key })` | 点線の枠・息をする絵・一言・次に押すキー |

| ヒーローの札 | `uxpFace(sprite, { scale, win, breathe, off, mark })`・`uxpHero(sprite, { name, sub, tags, … })` | 顔は、もとの 64px の整数倍（1・2・3）。にじませない・flex の子でも伸びない。`win` を絵より小さくすると、顔のまわりだけを切り取る（一覧のカードの絵は `win: 56`） |
| 打たれる札 | `uxpStamp(label, { kind })` → `hit(shakeEl)`・`show()`・`hide()` | 決めたあとの「導入済」「承認済」「決定」。200ms・4 段で打たれ、音と小さな揺れ |
| 下に貼りつく決めるキーの帯 | `uxpFoot(弱いキー, 主のキー)` | 送っても下に残る。主のキー（`uxKey(..., { kind: 'main' })`）は 1 つ：前の層に出る |
| 小さな選びのキーの列 | `uxpSeg([{ value, label }], value, onChange)` | 2〜4 個から 1 つ。選んだキーは沈んで明るい面 |

- **組み方の例**（設備を買う札）：`uxpCard({ pic, name, tags: stamp.el, desc, foot: [値段, gap.el], right: 買うキー })`。押したら、足りなければ `gap.nudge()`、足りていれば本体の関数を呼び、`stamp.hit(card)`・`uxSfx('cash')`・上の帯の資金は自分で回る（`rollNumber`）。
- **画面は止めない**：開いたとき（`uxpPrint`・`uxpBars` の伸び・`uxpStat` の `key`）・値が変わったとき（`set`）・押したとき（`uxpSelect(…, true)`・`stamp.hit`・`gap.nudge`）に、必ず何かが動く。動きを減らすときは、全部すぐ出る。
- 押すキーは、どの接頭辞（`ux-`・`uxp-`・`uxs-`・`uxm-`・`uxc-`）でも、土台の `press()`（`uxKey`）で作れば同じ手応えになる：`press()` を通したキーには `data-ux-key` が付き、土台の初期化（`base.css`）と、いまの入口の手応え（`legacy.ts`）はこれを見る。
- 押せるカード（`uxpCard` の `onTap`）の中に置いたキー・ボタンを押しても、カードは動かない（`press()` が、中のキーから始まった押しを外側へ通さない）。
- **指を離した瞬間に動く**：`press()` は、操作を呼ぶ前に、続く click を 1 回だけ呑む（同じ場所の 24px 以内・400ms 以内に来たものだけ）。開いたばかりの窓の外側や、閉じたあとの地図に、その click が当たらない。画面ごとの守り（`s-press.ts` の `safe()`）は、もう要らない（残っていても害は無い）。
