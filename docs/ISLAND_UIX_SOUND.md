# 段 UIX1s：音の土台（合成の SE と、場面と勢いで変わる BGM）

方向 C「管制卓」の見本（`public/uixlab/c/js/audio.js`・`music.js`・`sfx.js`）の音を、本体（`src/island/uix/`）へ移した段。
音はすべて WebAudio でその場で合成する（素材のファイルは足していない）。基本のサイクル・ゲームの数字・セーブの版は変えていない。

- 新しい音は **`<html class="is-uxc">`（または URL の `?uix=1`）のときだけ**鳴る。付いていないとき（既定）は、今の音（`IslandSfx` の mp3 の効果音・`Sound` の mp3 の BGM）のままで、何も変わらない。
- 見た目の土台（UIX1a）とは別のファイルで作っている。こちらが見るのは、class と、`window` の `uxc:change`（`detail.on`）だけ。
- 音の見本帳：`?uix=sound`（SE を全部押して鳴らせ、BGM の場面と層を切り替えられる）。

## 2. まとめの経路

```
音源（1 音ごとの発振器・ノイズ）
  ├─ BGM：層（旋律・低音・分散和音・太鼓・和音の厚み）→ 曲の出口 ×2（切り替え用）→ BGM のバス → 角を丸めるフィルタ（6.2kHz）┐
  ├─ SE ：SE のバス ───────────────────────────────────────────────────────────────────────────────────────────┤
  └─ 環境：環境のバス（いまは鳴らすものが無い。次の段で使う）──────────────────────────────────────────────────┤
                                                                     まとめの音量 → コンプレッサー → 天井（0.82）→ 出力
```

- `AudioContext` は 1 つ。**最初に画面に触れたとき**に作り、電源の入る音（`boot`）→ 1 秒後に曲、の順で始める。
- **画面が隠れたら止め、戻ったら戻す**（`visibilitychange` で `suspend`／`resume`。止まっているあいだは音の時刻も止まるので、戻ったときに拍がずれない）。
- コンプレッサー（しきい値 −15dB・比 5・立ち上がり 4ms）と天井（0.82）の値は見本のまま。いちばん重なる場合でも音割れは 0（下の 8 章）。
- やまびこは 2 本：BGM 用（0.388 秒＝拍に合う）と SE 用（0.13 秒）。

## 3. 切り替え

| | 切（既定） | 入（`is-uxc`・`?uix=1`） |
|---|---|---|
| 効果音 | `IslandSfx`（mp3）がそのまま鳴る | `IslandSfx.play` の入口で新しい音へ付け替える（mp3 は読み込まない・鳴らさない） |
| BGM | `Sound`（mp3）がそのまま鳴る | mp3 は止める。合成の曲を鳴らす |
| 設定の音の欄 | BGM・効果音の入り切り（今のまま） | BGM の音量・効果音の音量・消音 |
| `AudioContext` | 今のもの（`IslandSfx`） | 新しいものを 1 つ（今のものは作らない） |

- 切のとき、`uxSfx` などは何もせずに戻る。今の音の呼び出しが変わらないことは `tests/island-uix1s.test.ts` で確かめている。
- 入り切りを替えたら、鳴っている曲を止めて入れ替える（`uxc:change` か、`<html>` の class の変化で気づく）。二重には鳴らさない。
- 入のあいだも、今の BGM の「流すはずの曲」（発掘・経営会議）は覚えたままなので、切に戻すと続きの場面の曲が鳴る。

## 4. SE

### 4-1. 音の口

```ts
import { uxSfx } from '../uix/sound';
uxSfx(name: string, opts?: { pitch?: number; voice?: number; step?: number }): void
```

- `pitch`：音程のずらし（半音。音程のある音に効く）。`voice`：喋る人（`blip`）。`step`：段（下の表）。
- 音程は、いつも**いま鳴っている曲の和音・音階**から選ぶ（押す音が曲に溶ける）。同じ音が続いても飽きないよう、音程・左右を少しずつ揺らす。
- 知らない名前・切のとき・まだ音を始めていないときは、何もしない。

| 名前 | 意味 | `step` |
|---|---|---|
| `press` | 押した（クリックと、和音の 1 音） | |
| `release` | 離した | |
| `open` | 開く（和音を上る） | |
| `close` | 閉じる（和音を下る） | |
| `page` | 紙テープを送る（めくる） | 送る数（省くと 7。4 以下は詰めて短く） |
| `tab` | タブを替える | |
| `lever` | レバーの目盛りの「カチ」 | 目盛り 0〜7（上がるほど高い） |
| `clunk` | レバーが落ちる「ガチャン」（承認） | |
| `lamp` | ランプが点く | 何個めか 0〜（上がるほど高い） |
| `coin` | 金貨。**続けて鳴ると音階を上がる**（1.2 秒空くと下から） | 何枚めか 0〜11（省くと自動） |
| `cash` | 買った（レジのベルと引き出し） | |
| `deny` | 足りない・押せない（やわらかい 2 音。責めない） | |
| `confirm` | 決定 | |
| `rankup` | 順位が上がった・大きな達成（音階を駆け上がって和音） | |
| `conquest` | 制覇：小太鼓の連打 → 次の小節の頭で一撃 → 曲が祝いの曲（4 小節）へ。全体で 2〜3 秒 | |
| `build` | 建てる（槌 2 回 → 土台がはまる）※足した音 | |
| `done` | できあがった | |
| `tick` | 桁が回る | |
| `blip` | 吹き出しの字（人ごとに波形と高さが違う） | 字の番号（`codePointAt`。句読点は鳴らない。省くと順に揺らす） |
| `toggle` | 切り替え | 0 で切（下がる 2 音）・それ以外で入 |
| `slide` | つまみ | 位置 0〜10 |
| `error` | 誤り（低い同じ高さを 2 回）※足した音 | |

`blip` の `voice` は 0〜9 の声の表を回して使う（0〜4 は見本の 5 人ぶんの値、5〜9 は同じ決まりで足した）。

### 4-2. 足した名前（同じ `uxSfx` で鳴らせる）

`sale`（地図で 1 つ売れた）・`deposit`（入金）・`stamp`（承認済が点く和音）・`bell`（月の締めの鐘）・`flap`（札がめくれる）・`print`（1 行を打ち出す）・`zoom`（寄る。`step` 0 で戻る）・`roll`（小太鼓の連打 1.4 秒）・`firework`・`boot`（電源）・`dock`（帯がはまる）・`streak`（制覇までのランプ）・`leverback`。ここまでは見本にある音。
`built`（建物の完成）・`dig`（発掘のマスを打つ。`step`＝深さ）・`clink`（つるはしが石に当たる）は、今の音の付け替えに要るので足した。

### 4-3. 重なりの上限

- **同じ名前は 40ms 以内なら 1 つ**。見本が自分の間隔を持つ音は、見本の間隔のまま（`lever` 28ms・`slide` 30ms・`blip` 34ms・`coin` 42ms・`tick` 46ms・`flap` 50ms・`deposit` 90ms・`done` 120ms・`sale` 160ms）。
- **同時は 12 本まで**。超えたら新しい音を鳴らさない。節目の音（`clunk`・`rankup`・`conquest`・`stamp`・`bell`・`boot`）だけは通す。
- 新しい部品と、下の「全体のボタンの音」が同じ音を同時に頼んでも、この間引きで 1 つになる。

### 4-4. 全体のボタンと、札の出入り（入のとき。見た目は触らない）

- 使える `button` を**押した瞬間**（pointerdown）に `press`、離したとき（pointerup）に `release`。
  - 今の「ボタンを押したら tap」（click のとき）は、指で押した直後なら重ねない。キーで押したときは `tap` が `press` になる。
  - 自分の音を持つ部品には `data-ux-quiet` を付ける（ここでは鳴らさない）。
- `#isl-ui` の子の出入りを見て鳴らす：札・窓が出たら `open`、消えたら `close`、札から札へ替わったら `tab`。吹き出し（`.isl-pop`）の出入りも同じ。新しい部品の class は `ux-sheet`・`ux-modal` を同じ扱いにしてある。
- 資金の数字が回っているあいだ `tick`。

## 5. BGM

### 5-1. 場面と曲

どの曲もハ長調／イ短調で、音色の決まりは同じ（旋律＝矩形波か三角波・低音＝三角波・分散和音＝細い矩形波・太鼓＝ノイズと正弦波・和音の厚み＝幅の広い矩形波）。

| 場面 | 曲 | 速さ・長さ | 層 | 本体でいつ鳴るか |
|---|---|---|---|---|
| 地図 | `map` | 116・64 小節（約 2 分 12 秒） | 2〜5（勢いで決まる） | ふだん |
| 月次報告 | `report` | 116・8 小節 | 旋律（三角波）・低音・分散和音・刻み | 月次報告の札・開幕の幕が出ているあいだ |
| 制覇 | `fanfare` | 116・4 小節（1 回だけ） | 5 層＋旋律の下に和音 2 声 | `uxSfx('conquest')`。終わると、その場面の曲へ戻る |
| セクタ選択 | `sector` ※ | 116・8 小節 | 5 層（旋律は三角波・太鼓は刻みだけ） | ランドマップの札 |
| 発掘 | `dig` ※ | 116・8 小節 | 旋律・低音・分散和音・太鼓 | 発掘の画面 |
| 経営会議 | `board` ※ | 116・8 小節 | 旋律（幅の広い矩形波）・低音・太鼓・和音の厚み | 経営会議 |
| タイトル | `title` ※ | 100・16 小節 | 5 層（前半は低音と太鼓が休む） | いまの本体にタイトルの画面が無いので、見本帳だけ |

※ はこの段で足した曲。`map`・`report`・`fanfare` は見本の値のまま。

- 足した曲の作り：
  - `sector`：長い音で上がっていき、落ち着かない和音（Em）で止めて、次の行き先を待つ。
  - `dig`：短く切った動機と休みで、掘る手の拍を作る。太鼓は半分の速さで重く、裏拍につるはしの「チッ」。
  - `board`：歩みの拍。付点の弾みをくり返し、分散和音を入れずに乾いた響きにする。
  - `title`：地図の曲の主題を、ゆっくり・三角波で。
- **場面の切り替えは小節の頭**。前の曲の残り（伸ばした音の終わり）を 0.3 秒で消し、次の曲は別の出口から頭を鳴らす（短いクロスフェード。やまびこは次の曲へまたがる）。
- 本体の場面は、`p1/main.ts` の `uxSceneNow()` が出ている画面から読む（1 秒に 4 回）。**新しい画面は `uxScene('report')` のように自分から指定できる**（返り値を呼ぶと元へ戻る。こちらが優先）。

### 5-2. 地図の曲の層（会社の勢い）

層の順（旋律 → 低音 → 分散和音 → 太鼓 → 和音の厚み）は見本のまま。本体では、次の数だけ下から重なる（`level.ts`。ゲームの数字は読むだけ）。

| 層 | いつ重なるか |
|---|---|
| 旋律・低音 | いつも（見本と同じく、2 層が土台） |
| ＋分散和音 | **今月の売上のペースが、先月以上**（1 か月めは、1 つでも売れたら） |
| ＋太鼓 | **エリアの順位が上半分**（5 社・6 社なら 3 位以内。直近の月次報告の順位） |
| ＋和音の厚み | **エリア 1 位** |

- 売上のペース＝今月これまでの売上 ÷ 日数 × ひと月の日数。月のはじめ（5 日めまで）は読めないので、先月が先々月以上だったかで見る。境目で行き来しないよう、上がるのは 100% 以上・下がるのは 90% 未満。
- 層は小節の頭で出入りする（入るときは 1 拍かけて）。
- 旋律だけの 1 層は、本体では使わない。低音が入ると全体が約 11dB 大きくなるので、土台にすると小さすぎるため。見本帳では聴ける。
- いまの層は `uxMusic()`（`{ song, bar, beat, frac, layers, level }`）で読める（上の帯の層のランプ・拍の脈に使う）。

### 5-3. 地図の曲の構成（長く聴いても疲れないように足した変化）

見本の地図の曲は 16 小節（A 8 小節＋B 8 小節・約 33 秒）のくり返し。本体では、これを 1 巡めにして、64 小節（約 2 分 12 秒）でひと回りする構成にした。

| 巡 | 前半 8 小節 | 後半 8 小節 |
|---|---|---|
| 1 | A（見本のまま） | B（見本のまま） |
| 2 | **A の休み**：矩形波の旋律は休み、三角波のやわらかい声が長い音で和音をなぞる（分散和音が前に出る）。太鼓は頭の一打と刻みだけ。終わりの連打で戻る | B（**分散和音を別の順で**） |
| 3 | **C（つなぎ）**：足した 8 小節。A とは逆に「下りて、上り直す」形で、主和音から始める | B |
| 4 | A（**はじめの 4 小節は分散和音が休み**、5 小節めから入り直す） | B（分散和音を別の順で） |

- B の旋律は毎回同じ（戻ってくる所）。
- 2 層のときも、休みの節が無音にならない（三角波の声と低音が鳴る）。

## 6. 設定

- 入のとき、設定の音の欄は「BGM の音量」「効果音の音量」「消音」。押すたびに次の段へ（0 → 2 → 4 → 6 → 8 → 10 → 0）。値は 0〜10 で持つ（見本のつまみと同じ目盛り）。
- はじめの値は見本と同じ **BGM 7・効果音 8**。音量は 2 乗で効く。
- 保存先は今の音の設定と同じ鍵（`mycryptoisland.p1.sound`）。省略できる項目 `uxBgm`・`uxSe`・`uxMute` を足すだけで、今の項目（`bgm`・`se`）は書き換えない。セーブの版は上げていない。
- **古い設定では、今の入り切りを引き継ぐ**：BGM を消していたら BGM 0、流していたら 7。効果音も同じ（消していたら 0、出していたら 8）。

## 7. 見本から変えた所と理由

音色・音量の釣り合い・`map`（1 巡め）・`report`・`fanfare` は見本の値のまま。下の所だけ変えている。

| 変えた所 | 理由 |
|---|---|
| 予約する先を 0.16 秒 → **0.5 秒**（予約の時計の間隔が開いたら、その 2.5 倍・上限 2 秒） | 本体は、日が変わる処理などで画面の処理が 0.1〜0.4 秒止まる（調査の 7-3）。0.16 秒だと、そのたびに拍が遅れる。音の鳴る時刻・音色は変わらない |
| 過ぎてしまった音は捨てる（0.03 秒より遅れたら） | 長く止まったあとに、たまった音がまとめて鳴るのを防ぐ。拍の位置は保つ |
| 曲の切り替えで、前の曲の残りを 0.3 秒で消す | 指示の「短いクロスフェード」。見本との差は、祝いの曲 → 地図の切り替えの所で 16 ビットの 22 段（差の RMS −93dBFS） |
| 同じ曲をもう一度頼んでも、頭から鳴らし直さない | 場面の見直しを 1 秒に 4 回するため |
| 地図の曲の 2 巡めから（5-3） | 長く流れるため |
| 環境のバス | 指示の 3 本のバス。いまは鳴らすものが無い |
| 地図の曲の土台は 2 層 | 見本も 2 層から。旋律だけでは小さすぎる |

### 立ち上がりの「プチ」（決めてほしいこと）

- 見本の作りでは、ノイズの音の始まる時刻が標本の境目からわずかにずれると、音量の包みが効く 1 標本前に、ノイズの最初の 1 標本だけが元の大きさで出ることがある。出るかどうかは、端末の標本の速さと拍の位置しだい。
- 書き出しでは、`lever`・`coin`・`tick`・`slide`・`streak`・`build` のピークが、設計より 5〜20dB 高い 1 標本の尖りになっていた（8 章の表の 2 つのピークの差）。曲の太鼓にも同じ尖りが混ざる（振幅で最大 0.12）。音割れは無い。
- `engine.ts` の `clean` を true にすると、この 1 標本を出さない（ほかの値は変えない）。**既定は false＝見本のまま**（ユーザーが選んだ音を、聴かずに変えないため）。
- 見本帳の「立ち上がりの聴き比べ」で切り替えられる。耳で比べて決める。

## 9. 次の段へ（新しい画面が呼ぶもの）

- 部品の音：`uxSfx('press')` など。レバーは `lever`（目盛りごと）→ `clunk` → `lamp`（曲の 16 分音符の刻みで順に）→ `stamp`。自分の音を持つ部品には `data-ux-quiet`。
- 場面：`const off = uxScene('report')` → 閉じたら `off()`。
- 層のランプ・拍の脈：`uxMusic()`。
- 吹き出し：1 字ごとに `uxSfx('blip', { voice, step: 字.codePointAt(0) })`。
- 金貨の数え上げ：`uxSfx('coin')` を続けて呼ぶ（勝手に上がる）。
- 設定の画面を作り直すとき：`uxVol()`・`uxSetVol({ bgm, se, mute })`（0〜10）。
- 環境の音（地図の上の継続音）は、`Engine.env` のバスへ。

## 10. 耳で確かめていないこと

この段は、音を耳で聴かずに作っている。確かめたのは、見本と同じ値で鳴らしていること（音の並びと波形の一致）・ピーク・RMS・音割れ・無音・スペクトルの重心だけ。次は実機で聴いて決める。

- 足した曲（セクタ選択・発掘・経営会議・タイトル・地図の C の節と休みの節）と、足した SE（`build`・`built`・`error`・`dig`・`clink`）の聞こえ方。
- 今の 24 種の付け替え先の合い方（とくに `levelup` → `stamp`・`mission`／`win`／`mining`／`jingle` → `rankup` の重さ）。
- 立ち上がりの「プチ」を消すかどうか（7 章）。
- スマホのスピーカーでの低い音（`dock`・`clunk`・`dig` の重心は 70〜80Hz）の聞こえ方。
