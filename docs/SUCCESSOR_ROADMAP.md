# My Crypto Successor — ロードマップと機能の設計（提案）

`SUCCESSOR_VISION.md`（全体像）を、いまのゲーム（Lime の経営モード）の上にどう積んでいくかの設計。8 章の 4 点は決定済み。ほかの「提案」の数字は、各段を作るときに決めて `ISLAND_PHASE1.md` に仕様として移す。

---

## 0. 設計の芯（全部の機能で守ること）

1. **自分でやる → 分かる → 任せる**：どの部門も、最初は手で操作する遊びがあり、パネルで理解度が上がると、その操作をヒーローに任せられる。任せたあとも手で取り戻せる。
2. **任せると、視点が 1 段上がる**：手の作業が減ったぶん、1 段上の判断（部門の方針、セクタの戦略）が新しく遊べるようになる。任せた結果は月次報告に「担当の報告」として出す。
3. **特化もバランスも勝てる**：部門の奥（奥義）は特化に、掛け合わせはバランスに報いる。
4. **必要金額で遊ぶ時間を延ばさない**（これまでの決まり）。新しい部門の遊びは、新しい判断と新しい報酬で時間を作る。
5. **ランクが上がるたびに、新しい部門の遊びが 1〜2 個開く**：Common で覚えることを少なく、上のランクほど会社らしくなる。
6. **部門のやり込みは、それだけで楽しいゲーム**（ビジョン 8 章）：各部門に「手で上手くなれる判断」を 1 つ以上置く（下の 4 章の「手」）。パネルは判断を強くするもので、判断を置き換えるだけのものにしない。
7. **どの部門を極めても売上に効く**（ビジョン 8 章）：下の 4-0 の表のとおり、部門ごとに売上（または利益）への道を 1 本以上持たせる。特化した部門の奥義は、その道を大きく伸ばす。

## 2. 任せ方の 4 段

### 2-1. チームリーダー（業務を任せる）

各部門の「手で決めている判断」を、1 つずつ任せられる。

| 部門 | 任せられる業務の例 |
|---|---|
| 物流 | 素材の発注・作るものの選択・運ぶ便・品出し |
| R&D | 掘る場所の選択と自動の採掘（荒れ地を少しずつ掘る。お題は残す） |
| 人事 | 配置換え（詰まりの段へ人を回す）・休ませる |
| マーケ | 宣伝の出し直し |
| 経理 | 支払いのタイミング |

- 任せた業務の出来は、**リーダーの能力値** で決まる（例：発注は INT が高いほど過不足が少ない）。手でやるより少し悪い（7〜9 割）から始まり、奥義やパネルで手並みを超える。
- いまの自動発注（システムの枝）・自動化は、このチームリーダーの仕組みにまとめ直す。

### 2-2. 事業部長（部門を任せる）

- 部門の判断をすべて任せる。部門の画面に「部長におまかせ中」と出て、その部門の遊びは自動で回る。
- **部長の提案**：月に 1 回、部長が提案を持ってくる（承認／却下を選ぶカード）。
  - 例：「物流部長：配送センターを建てれば運搬の詰まりが消えます（120,000 G）」
  - 承認すると実行する。ここが、マクロの経営の判断になる。
- 部長の能力値とレアリティで、提案の質と、部門の効率の補正（±）が決まる。

### 2-3. セクター長（セクタを任せる）

- いまのマネージャー（セクタの抽象的な月の売上）と、7 段目の復興の委任を、セクター長にまとめ直す。
- 条件：その会社に事業部長が 3 部門以上いる（会社の形ができてから）。
- セクター長は、任せたセクタで部長たちの提案を自分で承認する（任せきり）。報告は月次報告にまとめて 1 行。

### 2-4. 後継者の育て方

- 任せたヒーローは、その役目で伸びる（7 段目の復興の担当の伸びと同じ流儀）。
- リーダー → 部長 → セクター長 と **昇進** できる（同じヒーローを育てて上げる楽しみ）。
- 役目ごとに向く能力値を変える：
  - 物流：AGI
  - 営業・マーケ：PHY（体力と押しの強さ）
  - R&D・経理・法務・システム：INT
  - 人事・総務・カスタマーサポート：3 つの平均

## 3. カリスマ度とヒーローのレアリティ

- **カリスマ度**（0〜100）を会社の数字に足す。上がり方：
  - 町の制覇：Common +3・Uncommon +6・Rare +10
  - 研究成果の発表：+1〜3
  - ブランド力に応じた分
  - 人事・マーケ・経営企画の奥義
- **雇える上限**（提案）：
  - 0：Novice
  - 15：Uncommon
  - 35：Rare
  - 60：Epic
  - 85：Legendary
- 上のレアリティほど、能力値の上限と伸びが高く、**部門の才能**（その部門のリーダーや部長のときに効く固有の効果。MCH のヒーローのスキルの雰囲気から決める）を持つ。
- 雇う画面に「カリスマ 42：Rare まで雇える（Epic まであと 18）」。

## 4. 部門ごとの遊び（設計案）

### 4-0. 部門の極め方と売上への道（ビジョン 8 章の柱 2）

| 部門 | 手で上手くなれる判断（やり込み） | 売上（利益）への道 |
|---|---|---|
| 物流 | 詰まりの段を見つけて人と投資を回す | 作れる・運べる数 → 売れる数 |
| 営業 | 商圏の場所取り、交渉の押し引き | 他社の客を奪う、卸の売上 |
| 経営企画 | 中期経営計画の方針、パネルの順番 | 選んだ部門の効き目の上乗せ |
| R&D | 掘る場所と層の読み、研究の順番 | 新しい商品（復刻品）、売値の上乗せ |
| 人事 | 誰をどこに置くか、育成と昇格 | 働きの速さ（すべての段） |
| システム | 自動化の順番、妨害への備え | 手間の削減、妨害の損失 0 |
| マーケ | 宣伝の打ち時、市場調査の読み、炎上の火消し | 需要とブランド力、企業の格による交渉の有利 |
| 法務 | 契約の条項選び、裁判の勝負 | 特許の使用料、他社の追随を止める |
| カスタマーサポート | 問い合わせへの答え方 | 顧客満足度 → リピーター（来店数） |
| 経理 | 節税と投資の時期 | 税の節約 → 投資に回るお金、コストの削減 |
| 総務 | 設備と福利厚生の順番 | 疲れと士気 → 働きの速さ |

### 4-1. 物流（いまの SCM を深める）
- 手：いまの調達 → 製造 → 運搬 → 販売。
- 新しく：詰まりの段を自動で直す「物流部長」。
- 奥義：
  1. 詰まりの警告が先に出る（来月の詰まりの予報）
  2. 全段の流れ +20%
  3. 詰まりが起きない（最も弱い段を自動で補う）

### 4-2. 営業（Rare から）
- **商圏の取り合い**（Rare ②）：地図の他社の店ごとに商圏（近くの家・お客さん）があり、近くに店を出すと奪える。売上で上回り続けた他社の店は **撤退** して空き地になり、すかさず出店できる。
- **販路の開拓**：他の町の他社に卸す契約（B2B）。安定した月の売上になるが、自分の店の売り場と取り合う。
- **仕入れの交渉**：問屋と値引きの交渉。マーケの「格」と法務の「契約」が効く。
- ~~**裏工作**（Epic から）~~：**後で考える**（8 章の決定 2026-11-02：他社との駆け引きの遊びは、いまは作らない）。
- 奥義：
  1. 撤退した他社の店の土地を、出店許可なしで取れる
  2. 卸の契約の枠 +2
  3. （裏工作は後で考える。奥義 3 はそのときに決め直す）

### 4-3. 経営企画（スキルツリー）
- **中期経営計画**：3 か月ごとに、方針を 1 つ選ぶ（売上の拡大／研究の強化／人材の育成／守り）。選んだ方針の部門のパネルが安く、効き目が上がる。
- 掛け合わせのパネルはここから開ける。
- 奥義：
  1. 中期経営計画を 2 つ同時に選べる
  2. 掛け合わせのパネルが安くなる
  3. 部長の提案がすべて見える（未来の提案の予告）

### 4-4. R&D（発掘・研究）
- 手：いまの発掘とダンジョン。
- 任せる：採掘のリーダー（荒れ地を自動で少しずつ掘る。お題と出土品の演出は自分で）。
- **研究のテーマ**（Uncommon から）：研究ポイントと月数で、新しい商品の系統や作業台を開発する（いまの「商品開発」を移す）。
- 奥義：
  1. 研究 Lv の上がりが速い
  2. 上のランクの出土品が出やすい
  3. 復刻品の売値 +30%

### 4-5. 人事（士気・給与を足す）
- **士気**（0〜100）をヒーローごとに足す。上がる：給与・休み・昇進・総務の環境。下がる：働きすぎ・同じ仕事の続きすぎ・炎上。士気が働きの速さに効き、低いと辞める。
- **給与**：ヒーローごとに月給（いまの人件費を見える化）。上げると士気が上がる。
- 任せる：配置換えのリーダー、雇用のリーダー（候補から自動で雇う）。
- 奥義：
  1. 研修で能力値の伸び +50%
  2. 辞める人がいなくなる
  3. 昇進したヒーローの才能が 2 つになる

### 4-6. システム
- いまの効率化（POS・自動発注・在庫管理など）。
- ~~**セキュリティ**・**サイバー戦**~~：**扱わない**（8 章の決定 2026-11-02：システムへの攻撃という題材は、このゲームで扱わない）。システムの遊びは効率化と自動化で作る。
- **ゲームの設定**：システムの画面の中に置く（いまどおり）。
- 奥義：
  1. （妨害・サイバー戦は扱わない。奥義は効率化の側で決め直す）
  2. 全部門の自動化の出来 +10%
  3. （同上）

### 4-7. マーケ
- いまの宣伝に加えて：
  - **市場調査**：町の需要と他社の売れ筋を数か月先まで見る。
  - **広報**：炎上を鎮める、良いニュースでブランド力を上げる。
- **企業の格**（ブランド力から決まる段：無名 → 地元の店 → 地域の有名店 → 全国ブランド → 世界ブランド）。格が営業の交渉・法務の契約・人事の採用に効く。
- **炎上**（Uncommon から）：裏工作の発覚・欠品の続き・不良品などで起きる。ブランド力と売上が下がる。広報とカスタマーサポートで鎮める。
- 奥義：
  1. 格が 1 段上に見える
  2. 炎上が起きにくい
  3. 宣伝の効き目が切れない

### 4-8. 法務（Epic から）
- **契約**：営業の卸・仕入れ、M&A の契約に「条項」を選ぶ（違約金・独占・期間）。法務の力で有利な条項を通せる。
- **特許・IP**：R&D の復刻品を特許にすると、他社が **追随できない**（いまの他社の追随を止める）。使用料が入る。
- **争い**：他社からの訴え（特許の侵害・契約違反）と、こちらからの訴え。裁判は数か月の勝負（法務の力・証拠・格）。
- 奥義：
  1. 契約で不利な条項を受けない
  2. 特許の期間 2 倍
  3. 裁判で負けない

### 4-9. カスタマーサポート（Uncommon から）
- **問い合わせ**：欠品・不良品・値段で、月に数件の問い合わせが来る。返事をする（手で選ぶ：謝る・返金・代わりの品）と顧客満足度が上がる。放っておくと下がる。
- **顧客満足度**（0〜100）：リピーター（来店の数）とブランド力に効く。
- **サポートセンター**（建物）：問い合わせを自動で受ける。
- 奥義：
  1. 問い合わせからリピーターが生まれる
  2. 炎上を未然に防ぐ
  3. 顧客満足度が下がらない

### 4-10. 経理（Uncommon から）
- **税**：四半期ごとに、利益に法人税（率はランクで上がる）。
  - ※必要金額で時間を延ばさない決まりとの兼ね合いを決める必要がある（下の「決めてほしいこと」）。
- **節税**：設備投資・研究開発・寄付を税から差し引く（総務・R&D・研究への寄付とつながる）。
- **見える化**：決算書（いまある）に「コストの大きい順」と「経理からの助言」（例：「倉庫の維持費が売上の 18%。統合で年 40,000 G の節約」）。
- 奥義：
  1. 税率 −5%
  2. 繰越の損失を使える（リセット後の税が軽い）
  3. 経理の助言どおりに自動で節約

### 4-11. 総務（Uncommon から）
- **疲れ**：いまのスタミナ（働く → 休む）を「疲れ」として見せる。
- **職場の環境**：休憩室・社員食堂・福利厚生などの設備で、疲れの回復と士気を上げる（いまの休憩室・福利厚生のパネルを移す）。
- **設備の投資**：工房や店の設備を新しくする（効率 +、税の節約は経理と）。
- 奥義：
  1. 疲れの回復 ×2
  2. 士気が下がらない
  3. 疲れが極限まで下がり、最高の働きを続ける（ビジョンの「極めると」）

### 4-12. ヒーローの育成（ビジョン 9 章。決定：上限と昇格のルール）

- **レベル**：Lv 1 から。レアリティの上限 Lv：Novice 40・Common 60・Uncommon 70・Rare 80・Epic 90・Legendary 100・Limited Legendary 120。
- **経験値**：働いた日・任された役目（リーダー・部長・セクター長・復興の担当）・研修で入る。役目が上ほど多い。
- **能力値**：MCH のデータの「Lv1 の能力値」から「最大 Lv の能力値」へ、Lv に合わせて緩やかに上がる（提案：もとのレアリティの上限 Lv で最大の能力値。昇格で上がったぶんは、その先へ少しずつ伸びる）。
- **昇格**：上限の Lv に届いたら、**強化アイテム** を使ってレアリティを 1 段上げる（Novice → Common → Uncommon → Rare → Epic → Legendary）。Legendary → Limited Legendary は **もとから Legendary のヒーローだけ**。
  - 強化アイテムの入り方（提案）：ダンジョンの深い層・町の制覇・研究成果の発表・依頼の報酬。上の段ほど珍しいアイテムが要る。
- **パッシブスキル**：Lv の節目（提案：10・30・50・70・90・110）とレアリティで、パッシブが増えたり強くなったりする。MCH のヒーローの固有のパッシブ（名前）を手がかりに、部門の才能（そのヒーローがリーダー・部長のときに効く）に結び付ける。
- 雇えるレアリティはカリスマ度で上がる（3 章）。育成では Novice からでも Legendary まで上げられる。

#### 段 E1 で決めた数字（2026-11。仕様は `ISLAND_PHASE1.md`「ヒーローの育成」、数字は `data.ts` の `HERO_GROWTH` の 1 か所）

| 項目 | 決めた数字 | 理由 |

## 6. 特化か、バランスか（提案の仕組み）

**経営者の目配り**（提案）
- 経営者（プレイヤー）は、**手で回せる部門の数** に上限がある（最初は 4、カリスマで最大 6 くらいまで）。
- 上限を超えた部門は、事業部長に任せないと効率が落ちる（目が届かない）。
- 任せた部門は目配りを使わない。→ 部門を広げるには任せることが要り、ゲームの芯（後継者に任せる）とつながる。

**特化に報いる**
- 部門の奥義（理解度 15・25・40）が強い（その部門の効き目が段違い）。
- 1 つの部門を深くすると、その部門のパネルが少しずつ安くなる（習熟）。

**バランスに報いる**
- 掛け合わせのパネル（どちらも理解度 10 以上）。
- 全部門 10 以上の「後継者の育成計画」。

**理論値**
- 全部のパネルを取る値段の合計は、ふつうに遊んだ収入の 3〜5 倍くらいにする（取れなくはないが、ふつうは特化かバランスのどちらかになる）。
- 無限パネルと寄付（6 段目）は、最後の余りの使い道として残す。
